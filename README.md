# Capstone Task Tracker

A small command-line project for practicing Git version control while tracking capstone work.

Run `python3 tracker.py`. It reports task counts and lists unfinished high-priority tasks using `tasks.csv`.

## Make it your own

Replace the sample tasks with your actual capstone tasks and add one useful improvement, such as an owner column or completion percentage. Commit your own changes before taking evidence screenshots. The supplied tasks are examples, not records of completed capstone work.

## Git practice

Use two branches to make different edits to the same line in `workflow.txt`, merge them, resolve the conflict by retaining both policies, and inspect the resulting history.

The starter files have no Git history. Run the practice commands yourself to produce your evidence. No GitHub repository or pull request has been created.
